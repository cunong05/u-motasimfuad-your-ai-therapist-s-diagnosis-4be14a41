This is my entry for the make.fun bounty **Your AI Therapist's Diagnosis**. It imagines what an AI therapist might write down after one very honest session.

## Entry

> Diagnosis: chronic main-character syndrome, complicated by 47 open tabs and the emotional range of a loading spinner.

## How to run it

```bash
python3 main.py
```

After it runs, open `/output/entry.txt` to see the single-line entry. The script also prints the entry's character count, which should be 117.

## Notes

The program uses only Python's standard library. It needs no extra packages, no internet connection, and no secrets or API keys to run.
