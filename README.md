## The entry

`main.py` writes one diagnosis line from an AI therapist to `/output/entry.txt` — a single line of at most 200 characters.

> Diagnosis: chronic main-character syndrome, complicated by 47 open tabs and the emotional range of a loading spinner.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

No dependencies, no network, no secrets. The program only writes the entry text.
